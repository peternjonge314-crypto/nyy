# Folio — Next.js Portfolio

A responsive, multi-page portfolio built with the Next.js App Router. Pages are server-rendered by default and use file-based routing.

## Run locally

- `npm install` installs dependencies.
- `npm run dev` starts the development server at http://localhost:3000.
- `npm run build` creates the production build.
- `npm start` serves the production build.

## Pages

- `/` — introduction and featured work
- `/about` — background, skills, and experience
- `/projects` — selected projects
- `/contact` — contact details and social links

Replace the sample name, biography, project details, email address, and social links with your own before publishing.

## Deploy

Import the repository into [Vercel](https://vercel.com/new) and use the default Next.js build settings. The same production build can also run on any Node.js host that supports Next.js.
